# Code of Conduct

## Our Standard

Storylio is a personal project maintained by a single owner. Interactions in this repository — issues, pull requests, and discussions — are expected to be respectful, constructive, and on-topic.

Specifically:

- Use clear, professional language
- Provide actionable feedback when reporting bugs or suggesting improvements
- Accept that not all suggestions will be implemented — this is a personal project with a specific vision
- Be patient; responses may not be immediate

## Unacceptable Behavior

The following will result in immediate removal:

- Harassment, personal attacks, or discriminatory language of any kind
- Spam, off-topic promotion, or irrelevant content
- Publishing private information about anyone without consent
- Any conduct that would be considered inappropriate in a professional setting

## Enforcement

The maintainer reserves the right to close issues, remove comments, and block users who violate this standard without prior warning.

## Reporting

If you witness unacceptable behavior, contact the maintainer directly at the address listed on [heinz.id](https://heinz.id).
